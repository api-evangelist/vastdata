VAST CSI Driver allows container orchestration frameworks such as Kubernetes to dynamically provision storage on a VAST cluster using the Container Storage Interface (CSI). VAST provides scalable, reliable, and fast persistent storage that can be accessed remotely by any Kubernetes application container.
