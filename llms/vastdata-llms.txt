# VAST Data

> VAST Data is an enterprise AI infrastructure company building a unified data platform for AI. The VAST AI Operating System combines VAST DataStore, VAST DataBase, VAST DataSpace, and VAST DataEngine to help organizations store, manage, process, and serve data for AI and deep learning at scale.

## Product

- [Platform Overview](https://www.vastdata.com/platform/overview): The unified VAST Data Platform powering AI infrastructure at exabyte scale
- [VAST AI Operating System](https://www.vastdata.com/platform/ai-os): Purpose-built operating system for the AI era with integrated engines for every layer of the stack
- [How It Works: DASE Architecture](https://www.vastdata.com/platform/how-it-works): The disaggregated, shared-everything architecture that decouples compute from storage for linear scaling
- [VAST DataStore](https://www.vastdata.com/platform/datastore): All-flash scalable storage for files, objects, and volumes (NFS, SMB, S3, Block, CSI) with Six Nines availability
- [VAST DataBase](https://www.vastdata.com/platform/database): AI-native database unifying structured data, vectors, streams, and metadata — 11x faster vector search at 91% lower cost
- [VAST DataSpace](https://www.vastdata.com/platform/dataspace): Globally-distributed namespace spanning on-prem, cloud, and edge at exabyte scale
- [VAST DataEngine](https://www.vastdata.com/platform/dataengine): Serverless execution and orchestration with event triggers, Python functions, and Kafka-compatible broker
- [VAST SyncEngine](https://www.vastdata.com/platform/syncengine): Scalable data discovery and migration service with automatic enrichment pipelines
- [VAST InsightEngine](https://www.vastdata.com/platform/insightengine): Real-time vector embedding and retrieval engine for RAG and agentic workflows
- [VAST AgentEngine](https://www.vastdata.com/platform/agentengine): Production-grade deployment layer for AI agents with containerized runtimes and MCP integration
- [VAST Gemini](https://www.vastdata.com/platform/gemini): Disaggregated storage consumption model combining hyperscale economics with enterprise appliance simplicity
